# IS459 final project artefacts

**TRACE | AML monitoring and connected-account investigation**

This package accompanies the final presentation. It covers the full 30 October 2026 pipeline execution on the synthetic IBM HI-Medium dataset and the TRACE dashboard that reads its published results.

- [Source code](IS459-AML-source.zip) contains the ingestion script, the full-v6 Spark jobs used for preparation, monitoring, connected-case detection and evaluation, the release publisher, and the TRACE dashboard source. The dashboard source includes the later Connected Cases interface update, which continued to read the same published data.
- The ZIP also includes the Step Functions workflow used to coordinate the run. Its resource references are CloudFormation placeholders. The archive is a source submission for review, with the original data and AWS environment supplied separately for a deployment.
- [Architecture overview](architecture/AWS_Architecture_Pack.pdf) describes the shared pipeline, Q1 monitoring and Q2 connected investigation.
